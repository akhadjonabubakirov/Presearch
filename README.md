# Presearch

Ideas worth thinking about. Essays, research, and observations about economics, data, technology, and the ideas shaping our world.

An independent, single-author publishing platform inspired by Medium and independent digital magazines.

## Features

- Editorial homepage with featured article, latest and popular stories, topics, and newsletter
- Explore page with search, category filters, and sorting (newest, oldest, most popular)
- Distraction-free reading experience (~700px text column) with claps, bookmarks, link sharing, comments, tags, related articles, and author profile
- Article content supports Markdown-style headings, quotes, tables, code blocks, and LaTeX-style equations
- Archive grouped by year and month with search and category filters
- About and Contact pages
- Private admin dashboard: stats overview, article management (edit, delete, feature), and a Markdown editor with draft / scheduled / published workflow
- Light and dark reading modes

## Categories

Economics · Data Science · Finance · AI & Technology · Research · Personal Insights

## Tech

- React 18 + React Router (frontend prototype with in-memory data)
- Vite for dev server and build

## Run locally

```bash
npm install
npm run dev
```

Then open the printed local URL (usually http://localhost:5173).

## Roadmap

- Phase 1: Homepage, article pages, editor, categories, search, archive, mobile responsiveness, SEO (current prototype)
- Next: Backend with Django REST Framework + PostgreSQL, comments/likes/bookmarks persistence, newsletter and subscriptions
- Advanced: analytics, recommendations, reader accounts and personalized feeds
